## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet client -> API | Untrusted request volume and payload size |
| API -> retailer image hosts | The server fetches third-party bytes on a client's behalf |
| client headers -> rate-limit key | CF-Connecting-IP is only trustworthy once the origin is Cloudflare-only |
| PyPI -> requirements.txt | Third-party code enters the app |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-14 | Denial of Service | all public routes, especially /api/v1/images | high | mitigate | slowapi default plus tighter per-route limits, 429 JSON (Tasks 2, 3) |
| T-1-15 | Denial of Service (memory) | image proxy body read | medium | mitigate | Streaming read aborted past MAX_BYTES; content type checked before reading (Task 2) |
| T-1-16 | Spoofing | rate_limit_key header trust | high | mitigate | CF-Connecting-IP honored only when TRUST_CF_CONNECTING_IP is true; default false until Phase 3 OPS-02 firewalls the origin (Task 2) |
